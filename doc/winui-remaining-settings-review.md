# Remaining settings sections and aggregate build

Audio, Subtitles, Chapters, Metadata and settings navigation have been reviewed against their WPF views and original resources. This completes the requested presentation pass; it does not claim full WPF feature parity.

- Audio: native source selection, codec, bitrate and track-name fields align using shared Compact form rows, with theme separators. Reload restores native preset audio mode; Clear explicitly selects silent/manual output. Existing one-output-per-source-track and custom lossy-bitrate capabilities remain; mixdown/sample-rate/gain/DRC/passthrough/lossless rule editors and multiple outputs per source track are separate functional gaps.
- Subtitles: foreign scan options and per-track flags/offset/name are compact related groups. Import remains UTF-8 SRT. Long implementation explanations are removed; WPF captions and available help are reused. Imported tracks now support Default with an additive backwards-compatible bool property. Burn and Default are mutually exclusive per imported/internal track; one burn and one default are coordinated across relevant tracks. Default counts are also validated in both capture and native-job construction. Reload restores preset subtitle mode and Clear explicitly removes manual subtitles/imports/search. Full selection-behavior dialogs and non-SRT external import remain separate gaps.
- Chapters: native table layout for number, source duration and editable name. CSV/TSV import and CSV export use the same shared App.Core CsvHelper as WPF; import validates the complete chapter-number set before any mutation. Source duration is never changed. Reset restores source names, using the original Chapter {0} fallback. XML/TXT import and WPF's partial-count confirmation workflow are not advertised by this picker.
- Metadata: four supported annotation overrides use a shared label/value form and native multiline comments. Source values are shown as placeholders only when metadata passthrough is enabled. Artist/Album captions are actual annotation keys in WPF's generic metadata grid. Queue capture/metadata mappings remain unchanged; this is not a new complete metadata scraper or arbitrary-annotation editor.
- Navigation: native SelectorBar with the eight original WPF section captions, no document-tab outlines or separators. Horizontal native scrolling handles overflow. Each page retains its own ScrollViewer/control instances in EditorPages; navigation changes visibility and does not reapply a preset or discard edits. Queue detail tabs are separate and unchanged.

Static validation: XAML/project XML, duplicate names, shared HB resources, x:Bind properties, events, programmatic widget ownership, original WPF resource keys and eight-page order. Original WPF AudioView, SubtitlesView, ChaptersView, MetaDataView and ChaptersViewModel and App.Core CsvHelper were read. FileSavePicker's WindowId/path-based API was checked against official Microsoft documentation. Local .NET/Windows execution is unavailable.

The user authorized an aggregate Windows build after this pass, including all preceding preset/Summary/Dimensions/Filters/Video/Compact changes. The source branch retains manual-only workflows. A dedicated build branch adds a push trigger scoped only to its exact name to run the existing integrated workflow; no broad automatic builds are enabled. The workflow performs managed preflight first, then restores or builds matching libhb and packages the framework-dependent x64 frontend. Compilation/package checks and Windows visual/native-encode acceptance must be reported separately.

Windows acceptance: all pages reachable, horizontal selector keyboard/scroll behavior and edit preservation; native resource lookup; track layouts at narrow widths/large text and High Contrast; silent output/Clear and preset Reload; internal/imported/default/burn combinations and old queue restore; SRT Unicode/offset handling; CSV quoted Unicode names and invalid/duplicate/mismatched numbers with no partial mutation; metadata passthrough placeholders and queue overrides; full native encode to a writable output path. The aggregate workflow's compiler and package results will be reported with its run/artifact links, without claiming interactive visual verification.
