# Dimensions presentation and shared WPF text

Dimensions now separates Source Dimensions, Orientation and Cropping, Resolution and Scaling, Borders, and Final Dimensions. Independent groups use shared three/two/one-column form breakpoints through CompactUi.ReflowSettingsGroups; width/height use AlignedFormRow. Native NumberBox controls retain spatial crop placement. Long implementation prose is removed. Source storage/display/aspect and resolved final storage/display/aspect/PAR are separate. Final dimensions reuse the same resolved native job used by Summary, with stale output cleared on edits or source reset. Native resolved size/crop populate disabled fields when using the preset; programmatic refresh is guarded to avoid event loops.

Scope: manual pixel dimensions/crop remain editable via the existing GeometryOverride path. Rotation, flip, resolution limits, anamorphic and padding settings are presented as read-only preset values, not nonfunctional controls. Independent editing of those WPF features remains a separate functional gap. Encoding mappings, saved queue schema and preset rules are unchanged. Settings tabs remain deferred.

Resources/WpfText.cs reads the original neutral Resources.resx and ResourcesTooltips.resx from HandBrakeWPF/Properties, linked as embedded resources by the WinUI csproj. No WPF control assembly dependency or copied resource catalogs are introduced. Summary and Dimensions labels/tooltips and source-header help now use original keys rather than duplicated explanatory strings. Native preset descriptions and actual diagnostic messages keep their own accurate source. App-specific commands still need purpose-specific copy; this change does not claim migration of every label in every page or support for WPF satellite-language catalogs.

Static checks: XML/project parsing, unique XAML names, event handlers, shared HB resources, x:Bind properties, NumberBox ownership, and existence of all referenced original label/tooltip/enum keys. Neutral WPF catalogs were inspected and contain only string data. No .NET SDK or Windows runtime is available locally. No compilation, Windows visual test or build was performed.

Windows acceptance: resource-manager lookup and x:Bind startup; normal/compact font sizing, 3/2/1-column transitions and enlarged text; crop spatial layout and keyboard order; source reset/switch, preset selection/reload and queue-edit restore; manual dimensions/crop, rotation/flip, non-square PAR, every padding mode; unavailable job settings must clear stale final dimensions; switching between Summary and Dimensions must not reapply settings or create refresh loops.
